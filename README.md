## 팀원
- 20515 윤혁빈/20716 송하율
## 질문
"제로 칼로리 음료수는 정말 건강상 이점이 있는가"
## 왜 이 주제인가 (팀이 씁니다)
제로 칼로리 음료수가 제로 칼로리가 아닌 음료수보다 건강에 좋다는 소리를 듣고 두 명 모두 제로 칼로리 음료수를 즐겨 먹는다.하지만 실제로 제로 칼로리 음료수가 건강에 더 좋은지 확실하게 모른다.그래서 제로칼로리 음료수들의 영양 성분표를 분석해 실제로 건강상 이점이 있는지 확인하기 위해 골랐다.
- 20515 윤혁빈: 나는 처음에 제로 칼로리 음료수는 칼로리가 없어서 좋다고 생각했다. 내 생각이 맞는지 데이터로 확인하고 싶었다.
- 20716 송하율: 제로 칼로리 음료수는 당류가 아예 없다고 생각해서 제로 칼로리 음료수가 건강상 이점이 있다고 생각했다.실제 내 생각이 맞는지 데이터로 확인해보고싶다.
